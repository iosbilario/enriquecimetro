Dados abertos

Todo o conteúdo do Enriquecímetro é servido como JSON estático em URLs públicas e estáveis, com CORS aberto — na prática, uma API somente-leitura sem chave e sem limite além do bom senso. Use livremente em reportagens, pesquisas e aplicações, citando a fonte primária (TSE) e este projeto.

Endpoints

  • public/data/meta.json — manifesto: fontes oficiais utilizadas, datas de download e processamento, contagens, metodologia do indicador de outlier e opções de filtro.
  • public/data/rankings.json — top 100 por categoria (aumento nominal, percentual, patrimônio atual, redução, multiplicador). Somente candidaturas com correspondência exata entre eleições.
  • public/data/search-index.json — índice compacto de todas as candidaturas (formato colunar: chave fields + linhas em items).
  • public/data/states/{UF}.json — mesmo formato do índice, por estado (ex.: SP).
  • public/data/candidates/{xy}.json — detalhes completos (bens item a item), em 256 shards pelos 2 primeiros caracteres do id do candidato.
  • public/photos/manifest.json — manifesto das fotos oficiais de urna (miniaturas em public/photos/{id}.webp).

Garantias e limitações

  • Os dados são regenerados diariamente a partir do TSE; meta.json traz o carimbo de tempo de cada processamento.
  • Nenhum arquivo contém CPF, e-mail, título de eleitor ou endereço — uma validação automática bloqueia a publicação se detectar dados pessoais.
  • Valores são os declarados à Justiça Eleitoral, nominais, sem correção monetária.
  • O identificador do candidato é estável entre atualizações (derivado do número sequencial público de candidatura do TSE).

Como citar

Enriquecímetro — variação patrimonial declarada por candidatos (dados do TSE/Portal de Dados Abertos). Disponível em https://iosbilario.github.io/enriquecimetro/

Para reproduzir do zero, o pipeline completo está no repositório (MIT).

Uma variação patrimonial elevada, por si só, não representa evidência de irregularidade. Os valores exibidos correspondem às declarações apresentadas à Justiça Eleitoral.
